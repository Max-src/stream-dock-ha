# Credits

How to talk to the Stream Dock 293S comes from public, independent work:

- [mirajazz](https://github.com/4ndv/mirajazz) by Andrey Viktorov (MPL-2.0), used as a library.
- [opendeck-akp153](https://github.com/4ndv/opendeck-akp153) by the same author: USB ids, key numbering and picture format.
- [StreamDock-Device-SDK](https://github.com/MiraboxSpace/StreamDock-Device-SDK), the manufacturer's public kit: the side band's positions, size and that it is display-only.
- [mrsvi.streamdeck](https://github.com/xecaz/mrsvi.streamdeck) by xecaz: sending pictures as a batch before one refresh, and what to avoid.
- [parsec-vdd](https://github.com/nomi-san/parsec-vdd) by Nguyen Duy (BSD-style licence): how to control the Parsec Virtual Display driver, which is Parsec's own work.
- [mirabox-streamdock-node](https://github.com/rigor789/mirabox-streamdock-node) by rigor789 (MIT): the startup picture command.
- [Home Assistant](https://developers.home-assistant.io/docs/api/websocket/): its public WebSocket API.
- [StreamDock ES](https://github.com/pilahito/streamdock-es): the note that these pads have 15 keys rather than 18.

Fonts for key icons and titles come from `epaint_default_fonts` (Ubuntu Font Licence, OFL).

Icons are [Material Design Icons](https://pictogrammers.com/library/mdi/) 7.4.47 by the Pictogrammers group, the set Home Assistant uses (Pictogrammers Free License, Apache 2.0; see `assets/mdi-license.txt`).
